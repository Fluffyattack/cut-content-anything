# Release history

Release history answers "was this ever out there, and in what form?". It is
recorded separately from the four evidence statements.

| Scope | Question |
| --- | --- |
| `asset_distribution` | Were these bytes distributed in a release? |
| `playable_release` | Could players reach it in a regular released version? |
| `project_release` | Was the game or project itself released? |

Statuses: `released`, `unreleased_candidate`, `unreleased_confirmed`, `unknown`.

## Good evidence

- The official release archive contains the same file (compare SHA-256).
- Official patch notes or version histories that add or remove the content.
- Developer statements naming the content.

## Not evidence

- Words like `beta`, `test`, `proto`, `unused` in a name.
- A debug menu being the only route.
- An empty web search.
- One region or revision, when others were not checked.

Record with `cutcontent release set` and keep the URLs and the date. The gallery
shows release history next to, not inside, the evidence statements.

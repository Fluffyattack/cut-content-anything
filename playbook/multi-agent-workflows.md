# Several agents on one investigation

Large games split well into independent tracks:

| Track | Output |
| --- | --- |
| Public research | Source list with claims, dates and coverage |
| Format and decoder | Reader, decoder notes, scene packages |
| Reference analysis | Candidate list with coverage |
| Developer functions | Search coverage, routes, operated menus |
| Runtime | Executed loads with measurements and screenshots |
| Independent review | Names and rights review; re-check of claims against evidence |

Rules:

- One owner per file or case record; others propose changes.
- Every track writes notes as it goes, in the private case folder.
- A reviewer that did not do the work checks the final claims against the
  recorded evidence before anything is reported as done.
- Software changes get an independent review of names, texts and third-party
  material for trademark and copyright issues. Required format names and
  licence notices stay as they are. An automated name check is not legal clearance.

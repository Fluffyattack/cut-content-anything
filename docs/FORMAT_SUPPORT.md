# Format support

Each reader describes the file structure it can inspect, the previews it can show,
and the exact evidence behind its support level. Format names are used only where
they are necessary to identify an input. A scan or preview does not establish that
the game itself runs. Runtime observations are recorded separately per exact build.

This table is generated from the adapters (`bin/cutcontent formats --markdown`).
The test suite checks that the document matches the current code. Local read-only
checks used 231 cartridge images, 28 parameter-file disc images and two other
disc images. The original files and private reports are not in this repository.

Support levels:

- **tested**: read, analysed and previewed; covered by automated tests
- **partial**: partly supported; see the notes
- **detection_only**: recognised and described, content is not read
- **not_supported**: recognised, then refused with a reason

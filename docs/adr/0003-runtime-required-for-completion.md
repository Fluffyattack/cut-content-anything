# Every completed investigation includes a real game start

The owner chose an actual start and operation of the exact local game build as
a requirement for completing any investigation, including questions that begin
with static data. Every map reported as a finding must also be loaded in the
actual game. The original stays read-only; a documented isolated test copy may
provide a load route when ordinary play has none. This test does not establish
normal-play reachability.

Every investigated game also receives a documented search of available data,
shipped code and public sources for developer menus, level or stage selection,
sound tests and test rooms. Found functions are operated in the game before
they are called functional. Search coverage is reported without claiming to
prove absence.

Scans, decoded previews and web sources can establish useful intermediate
findings, but the case remains open if the game or a reported map cannot be
loaded. Record the specific failure and use a second suitable method to
investigate it. If a lawful local firmware or runtime component is missing,
ask whether the owner can supply their own copy; never download it.

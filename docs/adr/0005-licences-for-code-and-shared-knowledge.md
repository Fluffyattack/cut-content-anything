# Licences for code and shared knowledge

The owner chose to make the project open for contributions: the project's own
code is to be licensed under MIT, and the directory, playbook, skills and
templates under CC BY 4.0. Before the licence files are added, the exact
requirements are researched from official sources: the licence texts, how they
apply to existing third-party parts (three.js MIT, LibreQuake BSD 3-Clause and
GPL material, GPL native helpers kept outside this repository), contributor
terms and the README and package metadata. Existing third-party notices stay as
they are. Until this is done, the README still states that the repository is not
open source.

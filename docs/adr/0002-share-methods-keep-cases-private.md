# Share methods and keep game cases private

The owner chose to publish reusable readers, research methods and general format
knowledge, while keeping game-specific reports, paths, screenshots and save data
local. This allows the shared skill to improve across investigations without
exposing the owner's game library or redistributing game content.

The owner explicitly allowed the existing public demo case based on freely
licensed LibreQuake data to stay public. The data's source and redistribution
terms remain documented. This exception
does not extend to the owner's other games or future cases.

# Seed the directory from checkable sources

The owner wants the directory filled with 10 to 20 entries, preferring free or
open-source games whose data can be checked locally, so entries can reach
`data-verified` or `runtime-verified` rather than staying `source-reports`. Only
opened primary sources are cited. Investigations should also look for content
that no public source describes yet. Such content is recorded as a local
finding; it is called unreleased only when checked sources establish that for
the stated scope.

# Publish game cases only for legally free games

The owner decided that findings about their own games stay private. A case,
directory entry or write-up about a specific game is published only when that
game's data is free to use and redistribute (for example an open-source or
freely licensed game). That status is checked against the game's own licence
texts and official sources before anything is published. A game that is merely
free to download is not enough. This refines decision 0002; the LibreQuake demo
remains the reference example.
